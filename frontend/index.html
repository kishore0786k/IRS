Channel Model
h = sqrt(K/(K+1)) * h_LOS + sqrt(1/(K+1)) * h_NLOS PL(d) = c / (4 * pi * f * d)^alpha * shadowing

The backend includes correlated Rician fading, distance-dependent loss, shadowing, CSI error, and phase noise so the results are not limited to an ideal passive surface model.

NOMA and OMA
x = sum_k sqrt(a_k * P_t) * s_k , sum_k a_k = 1 SINR_k = signal / (stronger-user interference + residual SIC + noise)

The dashboard compares IRS-assisted NOMA and OMA using the same channel family and reports sum-rate and fairness trends across IRS size.

Secrecy Metric
R_s = [log2(1 + gamma_leg) - log2(1 + gamma_eve)]^+

The model simulates a separate eavesdropper link and measures how much secure rate remains after the reflected path is shaped toward the legitimate receiver.

Publication Angle

The strongest defensible contribution is the joint study of IRS phase control under imperfect CSI, hardware impairment, and secrecy-aware optimization rather than a generic "IRS improves SNR" claim.

  • Show improvement over greedy, random, and direct-link baselines
  • Report confidence intervals and Monte Carlo convergence
  • Include CSI-error robustness and secrecy degradation curves
  • Use a consistent simulation-to-figure pipeline
